# Google Search Console Indexing Checklist

Owner action required: this checklist must be completed from the Google account that owns the clinic website property.

## Property

- Website: `https://drhaithamsharshar.com`
- Sitemap: `https://drhaithamsharshar.com/sitemap.xml`
- Robots file: `https://drhaithamsharshar.com/robots.txt`

## Submit Sitemap

1. Open Google Search Console.
2. Select the domain property for `drhaithamsharshar.com`.
3. Open Sitemaps.
4. Submit `https://drhaithamsharshar.com/sitemap.xml`.
5. Confirm the status is Success.

## Check After Submission

- Page indexing shows Submitted and indexed or Crawled currently not indexed.
- Sitemap report shows the latest fetch date.
- Enhancements show no structured data errors for FAQ or breadcrumb items.
- Performance report starts showing queries for Gulf, Saudi, UAE, Kuwait, Qatar, Oman, Bahrain, Europe, UK, Germany, Cairo, implants, crowns, veneers, full arch, and dental tourism.

## Proof To Save Before Calling It Indexed

Save dated screenshots or exports from the owner account for each priority URL:

- URL Inspection shows the exact inspected URL and the declared canonical.
- Live Test shows the page is crawlable and its rendered HTML is available.
- Page Indexing shows the current status; do not describe Requested as Indexed.
- Sitemaps shows Success and a fetch date after the deployment date.
- Rich Results Test shows only schema that is also visible on the page.
- The owner-approved HS Dental Cases page is present in the sitemap with its documented publication consent and image-search approval.

Local build output, a sitemap file, or a green test is not Search Console proof. Production
deployment and owner-account inspection require separate approval.

## Weekly Review

- Check which pages get impressions but low clicks.
- Improve titles and opening paragraphs for those pages.
- Add internal links from high impression pages to the regional guides.
- Do not add fake reviews, fixed prices, guaranteed results, or diagnosis claims.
